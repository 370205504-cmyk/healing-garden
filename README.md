## 🎮 核心玩法

### 🌱 种植系统
- 8块花园地块（初始4块，可解锁）
- 5种花卉：向日葵🌻、玫瑰🌹、郁金香🌷、樱花🌸、稀有花💎
- 5阶段生长：种子→发芽→成长→花苞→开花
- 浇水/施肥机制

### 🎁 道具系统
- 种子系统（5种）
- 工具系统（水壶、肥料、小太阳）
- 材料系统（水滴💧、金币💰、水晶💎）

### 🏆 成就系统
- 16项成就
- 种植、收获、分享、签到成就
- 成就奖励发放
