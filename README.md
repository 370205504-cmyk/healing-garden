## 项目概述

《自动治愈花园》是一款专为18-35岁碎片化时间多、精神压力大的年轻用户打造的治愈系休闲小游戏。游戏主打离线自动成长、无强制任务、无内卷焦虑、纯情绪价值输出，通过种植花卉、打造专属花园来缓解压力、治愈心灵。

## 核心特色

- **零压力体验**：花卉全程自动生长，不浇水、不上线也能正常盛开
- **情绪疗愈**：每款花卉附带专属花语与疗愈属性，收获时触发治愈文案
- **双平台适配**：一套核心代码，微信 + 抖音双平台无缝兼容
- **碎片化覆盖**：生长周期覆盖10分钟-12小时全场景，日均在线仅需10-15分钟
- **零压力机制**：花卉始终自然生长，无需担忧，纯治愈体验

## 技术架构

### 核心设计原则

1. **一套核心代码 + 双平台隔离适配层**架构
2. 业务代码**禁止**直接调用 `wx`/`tt` 原生API
3. 所有平台接口必须通过统一 `Platform` 对象调用
4. 双平台差异化逻辑通过 `Platform.isWx`/`Platform.isTT` 判断隔离

### 强制开发规范

#### 1. 存储路径规范
- 所有文件**必须**存储在 `D:\AutoHealingGarden\` 目录下
- **绝对禁止**写入C盘任何目录
- 资源文件必须使用相对路径引用

#### 2. 代码规范
- 使用ES5语法，兼容微信基础库3.15.1+、抖音基础库2.0.0+
- 统一使用2个空格缩进，禁止混用tab和空格
- 所有代码末尾必须加分号，禁止依赖ASI
- 对象、数组的最后一个属性/元素**禁止**加尾逗号

#### 3. 兼容性规范
- 业务代码中**禁止**直接使用 `window`、`document`、`navigator` 等浏览器对象
- 如需保留H5兼容代码，必须加严格环境判断：`if (typeof window !== 'undefined') { ... }`
- 所有 `game.js` 文件必须把【固定兼容垫片与全局错误捕获代码】放在文件最顶部

#### 4. 运行时安全规范
- 所有字符串方法必须使用固定写法：`(变量 || '').方法名()`
- 所有对象属性调用必须使用：`(对象 || {}).属性` 或 `(对象?.属性 || 默认值)`
- 所有数组方法必须使用：`(数组 || []).方法名()`
- 所有API调用必须补全 `success`/`fail`/`complete` 回调

## 核心玩法系统

### 花园地块系统
- 初始解锁6块圆角花田，随花园等级逐步解锁，最高24块
- 4行6列竖屏固定布局，每块花田独立运行
- 花田5种状态：可播种 → 生长中 → 可收获 → 枯萎可清理 → 可播种（循环）
- 花园友好机制，枯萎后一键清理即可恢复

### 花卉种子系统
- **普通花卉**：初始解锁，短周期（10分钟-2小时）
- **稀有花卉**：等级解锁，中长周期（2-12小时）
- **情绪专属花卉**：带专属花语与疗愈属性
- **限定花卉**：节日/活动/图鉴套装解锁

### 图鉴收集系统
- 每收获一种花卉，自动点亮对应图鉴
- 解锁花语、养花知识、生长周期记录
- 按主题划分花卉套装，集齐解锁专属奖励

### 花园装扮系统
- 装扮分类：远景背景、中景装饰、前景治愈装饰
- 所有装扮无任何属性加成，纯个性化治愈
- 支持用户自由摆放，打造专属花园
