# 🎮 《治愈花园物语》v8.0 - 深度玩法设计文档

> **对标**: 《合成大西瓜》+《旅行青蛙》+《动物森友会》
> **核心理念**: 轻松上手 + 深度策略 + 强成就感

---

## 🌟 爆款游戏特点分析

### 1. 《合成大西瓜》成功要素
- **合成爽感**: 拖拽合并，视觉效果炸裂
- **策略深度**: 空间管理、合成路径规划
- **成就感**: 大西瓜、高分记录
- **社交传播**: 分享成绩、挑战好友

### 2. 《旅行青蛙》成功要素
- **养成治愈**: 收集、培育、等待
- **惊喜系统**: 随机事件、明信片收集
- **情感连接**: 与青蛙的情感羁绊

### 3. 《动物森友会》成功要素
- **自由度高**: 自由装饰、个性表达
- **收集驱动**: 收集全图鉴的强迫症满足
- **时间沉淀**: 长期游玩、慢慢积累

## 🚀 v8.0 核心玩法升级

### 一、合成系统（爽感核心）

#### 1.1 拖拽合成机制
```
🌱 → 🌿 → 🌳 → 🎋 → 🌴 → 🌲
小苗 → 幼苗 → 小树 → 竹子 → 棕榈 → 大树

合成规则：
- 相同等级的植物拖拽合并 → 升级成更高级植物
- 不同等级 → 无法合并
- 合成时有爆炸特效 + 金币奖励
```

#### 1.2 合成奖励系统
```
合成等级 | 植物类型 | 金币奖励 | 经验值 | 特殊效果
1级 → 2级 | 🌱→🌿 | +5 | +2 | 绿色光效
2级 → 3级 | 🌿→🌳 | +15 | +5 | 蓝色光效
3级 → 4级 | 🌳→🎋 | +30 | +10 | 金色光效
4级 → 5级 | 🎋→🌴 | +60 | +20 | 彩虹光效
5级 → 6级 | 🌴→🌲 | +100 | +40 | 全屏特效
```

#### 1.3 连击系统
```
连续合成触发连击：
- 2连击: 奖励 x 1.5
- 3连击: 奖励 x 2.0
- 4连击: 奖励 x 3.0
- 5连击: 奖励 x 5.0 + 全屏烟花
```

### 二、种子系统（策略深度）

#### 2.1 种子获取
```
获取方式：
1. 商店购买（金币）
2. 每日签到奖励
3. 成就解锁
4. 神秘礼盒随机
5. 好友赠送
```

#### 2.2 种子类型
```
普通种子（绿色）：
- 🌻 向日葵种子 - 10金币
- 🌷 郁金香种子 - 20金币
- 🌹 玫瑰种子 - 30金币

稀有种子（蓝色）：
- 🌸 樱花种子 - 100金币
- 💜 薰衣草种子 - 150金币

史诗种子（紫色）：
- 🌺 牡丹种子 - 500金币
- 🌻🌻 双头向日葵 - 800金币

传说种子（金色）：
- 🌈 彩虹花种子 - 2000金币
- 💎 钻石玫瑰 - 5000金币
```

#### 2.3 植物特性
```
每种植物有不同属性：
- 生长速度: 快/中/慢
- 收益倍率: x1 ~ x5
- 特殊能力: 加速周围、额外金币、经验加成
- 合成价值: 高级植物合成价值更高
```

### 三、花园装饰系统（自由度）

#### 3.1 装饰物分类
```
功能性装饰：
- 🏠 花房: 增加种植位 +1
- ⛲ 喷泉: 加速生长 10%
- 🦋 蝴蝶园: 增加金币掉落 20%
- 🐝 蜂箱: 增加合成奖励 15%

美观性装饰：
- 🌸 樱花树
- 🎋 竹林
- 🪨 假山
- 🌉 小桥
```

#### 3.2 自由布局
```
- 9x9 格子花园
- 自由拖拽摆放
- 保存多个布局方案
- 布局影响植物加成
```

### 四、成就与收集系统（强迫症满足）

#### 4.1 植物图鉴
```
收集度系统：
- 发现新植物 → 解锁图鉴
- 收集全部 → 获得称号和奖励
- 隐藏植物 → 特殊条件触发

图鉴等级：
🥉 青铜收集者: 收集 10 种植物
🥈 白银园艺师: 收集 30 种植物
🥇 黄金园丁: 收集 50 种植物
💎 钻石大师: 收集全部植物
```

#### 4.2 成就系统
```
成就分类：
1. 种植成就
   - 种植新手: 种植 10 次
   - 勤劳园丁: 种植 100 次
   - 种植大师: 种植 1000 次

2. 合成成就
   - 初次合成: 合成 1 次
   - 合成达人: 合成 50 次
   - 连击之王: 单次连击 5+

3. 收集成就
   - 图鉴开启: 解锁 10 种植物
   - 收藏家: 解锁 30 种植物
   - 完美主义: 解锁全部植物

4. 社交成就
   - 分享达人: 分享 10 次
   - 好友互助: 帮助好友 5 次
```

### 五、每日任务系统（日活留存）

#### 5.1 任务类型
```
每日任务（重置时间：0:00）：
- 🌱 种植 5 棵植物 → 奖励 50 金币
- 🌿 合成 3 次 → 奖励 100 金币
- 🌸 收获 10 次 → 奖励 80 金币
- 💰 累计获得 500 金币 → 奖励稀有种子 x1
- 🏆 完成所有任务 → 奖励神秘礼盒 x1

周常任务：
- 种植 50 棵植物 → 奖励 500 金币
- 合成 20 次 → 奖励史诗种子 x1
- 登录 7 天 → 奖励传说种子 x1
```

### 六、惊喜系统（随机性）

#### 6.1 神秘访客
```
随机事件（每日 3 次机会）：
- 🦋 蝴蝶仙子: 带来稀有种子
- 🐝 蜜蜂公主: 加速所有植物生长
- 🌈 彩虹使者: 随机提升一种植物等级
- 💰 金币雨: 全屏金币掉落
- 🎁 神秘礼盒: 随机奖励
```

#### 6.2 特殊天气
```
天气系统（每小时变化）：
- ☀️ 晴天: 正常生长
- 🌧️ 雨天: 生长加速 20%
- 🌈 彩虹: 合成奖励翻倍
- 🌸 花粉季: 收获金币 +50%
- 💫 星光夜: 稀有植物出现概率提升
```

### 七、社交系统（传播裂变）

#### 7.1 好友互动
```
好友功能：
- 参观好友花园
- 偷菜（限制次数）
- 赠送种子
- 互相浇水加速
- 挑战好友合成记录
```

#### 7.2 排行榜
```
排行榜分类：
- 💰 财富榜: 金币数量排名
- 🌱 种植榜: 种植次数排名
- 🏆 合成榜: 合成次数排名
- 🌸 收集榜: 植物种类排名
```

#### 7.3 分享传播
```
分享奖励：
- 分享游戏截图 → 获得 50 金币
- 分享合成记录 → 获得普通种子 x1
- 分享成就达成 → 获得稀有种子 x1
- 邀请好友加入 → 双方获得神秘礼盒
```
