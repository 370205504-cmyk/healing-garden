# 《自动治愈花园》产品需求文档

## 文档信息
- **文档版本**: v1.0.0
- **创建时间**: 2026-04-05
- **创建岗位**: 产品经理
- **项目名称**: 自动治愈花园 (AutoHealingGarden)
- **目标平台**: 微信小游戏（主）、抖音小游戏（备）

## 1. 项目概述

### 1.1 项目背景
随着生活节奏加快，用户对休闲解压游戏的需求日益增长。《自动治愈花园》旨在为用户提供一个轻松、治愈的游戏体验，通过简单的种植操作带来成就感和放松感。

### 1.2 产品定位
- **产品类型**: 竖屏休闲解压种植游戏
- **目标用户**: 18-35岁，寻求放松和解压的移动端用户
- **核心价值**: 简单操作、治愈体验、成就感积累
- **竞品分析**: 相比传统农场游戏，更强调治愈感和操作简便性

### 1.3 项目目标
1. **产品目标**: 7天内完成从0到1的自动化开发
2. **技术目标**: 建立可复用的自动化游戏开发流水线
3. **商业目标**: 通过激励视频广告实现变现
4. **质量目标**: 通过平台审核，用户评价4.0+

## 3. 功能需求

### 3.1 核心功能模块

#### 3.1.1 种植系统
- **功能描述**: 选择种子、种植、浇水、收获完整流程
- **用户故事**: 作为玩家，我想种植不同的植物，看到它们成长并收获
- **验收标准**:
  1. 支持至少5种基础植物类型
  2. 每种植物有完整的生长动画
  3. 收获时获得金币和经验
  4. 操作反馈及时明确

#### 3.1.2 花园系统
- **功能描述**: 自定义花园布局，放置装饰物品
- **用户故事**: 作为玩家，我想装饰我的花园，展示个人风格
- **验收标准**:
  1. 10×15网格布局系统
  2. 支持至少10种装饰物品
  3. 装饰物品可自由放置和移动
  4. 花园等级系统

#### 3.1.3 经济系统
- **功能描述**: 金币获取和消耗，游戏内经济平衡
- **用户故事**: 作为玩家，我想通过游戏获得金币，购买更多物品
- **验收标准**:
  1. 稳定的金币获取途径
  2. 合理的物品定价
  3. 激励视频广告兑换
  4. 经济数据持久化

#### 3.1.4 任务系统
- **功能描述**: 每日任务和成就系统，引导用户行为
- **用户故事**: 作为玩家，我想完成任务获得额外奖励
- **验收标准**:
  1. 每日任务系统（至少5个任务）
  2. 成就系统（至少10个成就）
  3. 奖励发放及时准确
  4. 进度跟踪和提示

#### 3.1.5 商店系统
- **功能描述**: 游戏内商店，购买种子和装饰
- **用户故事**: 作为玩家，我想在商店购买想要的物品
- **验收标准**:
  1. 分类清晰的商品展示
  2. 购买流程简单顺畅
  3. 库存管理和刷新
  4. 促销活动支持

#### 3.1.6 社交系统
- **功能描述**: 好友互动和社交分享
- **用户故事**: 作为玩家，我想和好友互动，分享我的花园
- **验收标准**:
  1. 好友添加和访问
  2. 礼物赠送功能
  3. 排行榜系统
  4. 分享到社交平台

## 5. 用户体验设计

### 5.1 交互设计原则
1. **简单直观**: 新手5分钟内掌握核心操作
2. **及时反馈**: 所有操作有明确的视觉或听觉反馈
3. **一致性**: 相同功能采用相同交互方式
4. **容错性**: 提供撤销和确认机制，减少误操作

### 5.2 核心用户流程
```
新用户进入 → 新手引导 → 首次种植 → 首次收获 → 
解锁功能 → 日常循环 → 社交互动 → 长期留存
```

### 5.3 界面布局
- **竖屏设计**: 适配单手操作
- **信息分层**: 重要信息突出，次要信息可隐藏
- **操作区域**: 底部固定操作栏，方便拇指操作

## 6. 商业化设计

### 6.1 变现模式
#### 主要变现：激励视频广告
- **双倍收益**: 观看广告获得种植双倍收益
- **免费种子**: 观看广告免费获得稀有种子
- **加速生长**: 观看广告立即完成植物生长
- **特殊装饰**: 观看广告解锁限定装饰

#### 变现原则
1. **自愿原则**: 所有广告自愿观看，不影响核心体验
2. **价值对等**: 广告奖励价值合理，用户愿意观看
3. **频率控制**: 合理控制广告展示频率，避免干扰

### 6.2 数据指标
#### 核心指标
- DAU（日活跃用户）
- 次日留存率（目标：40%+）
- 7日留存率（目标：20%+）
- 人均广告展示次数（目标：3-5次/日）
- ARPU（每用户平均收益）

#### 优化目标
- 提高用户留存和活跃度
- 优化广告展示效率和收益
- 提升用户满意度和口碑
