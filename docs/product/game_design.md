# 《自动治愈花园》游戏设计文档

## 项目信息
- **游戏名称**: 自动治愈花园 (AutoHealingGarden)
- **游戏类型**: 竖屏休闲解压种植游戏
- **目标平台**: 微信小游戏（主）、抖音小游戏（备）
- **目标用户**: 18-35岁，喜欢休闲解压游戏的用户
- **开发模式**: 100%自动化流水线开发
- **开发周期**: 7天（2026-04-05 至 2026-04-11）

## 核心玩法设计

### 游戏概述
《自动治愈花园》是一款竖屏休闲解压种植游戏。玩家通过点击、拖拽等简单操作，种植各种治愈系植物，打造属于自己的梦幻花园。游戏强调放松、解压的体验，适合碎片时间游玩。

### 核心循环
```
进入游戏 → 选择种子 → 种植浇水 → 等待生长 → 
收获植物 → 获得金币 → 解锁新种子/装饰 → 装饰花园 → 
分享成就 → 继续种植
```

### 游戏特色
1. **治愈系美术风格** - 柔和的色彩，简洁的UI，舒适的动画
2. **简单操作** - 点击、拖拽等单手操作，适合移动端
3. **成长系统** - 植物成长、花园升级、成就解锁
4. **装饰系统** - 多种花园装饰物品，个性化定制
5. **社交分享** - 分享花园成就，好友排行榜

## 功能模块设计

### 1. 种植系统
#### 功能描述
- 玩家可以选择不同种类的种子进行种植
- 每种植物有独特的生长周期和外观
- 种植需要消耗金币或观看激励视频获得

#### 技术实现
- **种子类型**: 基础种子（5种）、稀有种子（3种）、特殊种子（2种）
- **生长阶段**: 种子 → 发芽 → 幼苗 → 成株 → 开花 → 结果
- **交互方式**: 点击种植，拖拽移动，点击收获

#### 自动化生成要点
- 植物生长动画自动生成
- 植物属性数据驱动配置
- 种子平衡性自动调整

### 2. 花园系统
#### 功能描述
- 玩家拥有一个可自定义的花园空间
- 可以放置植物、装饰物、建筑等
- 花园有等级系统，升级解锁新功能

#### 技术实现
- **网格系统**: 10×15的网格布局
- **装饰类型**: 路径、围栏、喷泉、雕像、灯光
- **升级系统**: 经验值积累，等级提升

#### 自动化生成要点
- 花园布局算法自动生成
- 装饰物品属性配置
- 升级曲线自动平衡

### 3. 经济系统
#### 功能描述
- 金币作为主要游戏货币
- 通过收获植物、完成任务、观看广告获得金币
- 消耗金币购买种子、装饰、解锁功能

#### 技术实现
- **收入来源**:
  1. 植物收获（主要）
  2. 每日任务
  3. 成就奖励
  4. 激励视频广告
- **消耗途径**:
  1. 购买种子
  2. 购买装饰
  3. 解锁新区域
  4. 加速生长

#### 自动化生成要点
- 经济平衡自动调整算法
- 价格曲线自动生成
- 收益反馈循环设计

### 4. 任务系统
#### 功能描述
- 每日任务：每天刷新，提供稳定收益
- 成就系统：长期目标，提供大额奖励
- 特殊活动：限时活动，增加游戏活跃度

#### 技术实现
- **任务类型**:
  1. 种植任务（种X棵Y植物）
  2. 收获任务（收获X个Y果实）
  3. 装饰任务（放置X个Y装饰）
  4. 分享任务（分享花园X次）
- **奖励机制**: 金币、特殊种子、装饰物品

#### 自动化生成要点
- 任务难度自动平衡
- 奖励价值自动计算
- 玩家进度跟踪

### 5. 商店系统
#### 功能描述
- 种子商店：购买各种植物种子
- 装饰商店：购买花园装饰物品
- 特权商店：购买游戏内特权

#### 技术实现
- **商品分类**:
  1. 种子类：基础、稀有、特殊
  2. 装饰类：功能性、美观性
  3. 特权类：双倍收益、自动浇水
- **购买方式**: 金币购买、广告兑换、直接购买

#### 自动化生成要点
- 商品定价自动算法
- 库存刷新逻辑
- 促销活动生成

### 6. 社交系统
#### 功能描述
- 好友系统：添加好友，访问好友花园
- 排行榜：好友间种植竞赛
- 分享功能：分享花园成就

#### 技术实现
- **社交功能**:
  1. 好友列表
  2. 花园访问
  3. 赠送礼物
  4. 排行榜
- **分享功能**: 截图分享、成就分享、邀请好友

#### 自动化生成要点
- 社交互动规则
- 分享内容自动生成
- 排行榜算法
