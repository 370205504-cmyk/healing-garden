# 构建验证清单 (Build Verify Checklist)

> 每次构建后，按顺序逐项检查。**无真机验证 = 代码是薛定谔的可用。**

---

## 阶段 A：构建前检查（每次构建前执行）

- [ ] Git 提交了当前所有改动（git status 干净）
- [ ] 最近的代码变更已通过 TypeScript 编译检查
- [ ] 场景文件 `MainScene.fire` 存在
- [ ] 所有脚本组件已绑定到场景节点
- [ ] 包体预估 < 4MB（微信主包限制）

---

## 阶段 B：构建后检查（构建完成后）

- [ ] 构建成功，无错误日志
- [ ] 构建目录下生成了主要文件：
  - `game.js` / `game.ejs`
  - `game.json`
  - `project.config.json`
  - `assets/` 目录包含对应资源
- [ ] 构建产物总大小记录：____ MB
  - 主包大小（game.js + runtime）：____ MB
  - 资源目录大小（assets/）：____ MB

**如果主包 > 4MB：** 停止，进行分包或引擎裁剪后再试。

---

## 阶段 C：微信开发者工具检查

- [ ] 微信开发者工具导入成功
- [ ] 编译无错误（工具底部状态栏）
- [ ] 模拟器正常显示游戏画面
- [ ] 控制台无红色错误输出
- [ ] 无 `Error 1209`（settings.json 读取失败）
- [ ] 无 `TypeError: xxx is not a function` 等脚本运行时错误

---

## 阶段 D：真机预览检查

- [ ] 预览二维码正常生成
- [ ] 手机扫码后游戏正常启动（无白屏/黑屏）
- [ ] 首屏显示正确
- [ ] FPS ≥ 30（帧率稳定）
- [ ] 触摸交互正常（点击地块、种植、收获）
- [ ] 资源加载正常（无花屏/色块）

---

## 阶段 E：回归测试（修复后必做）

- [ ] 之前发现的 bug 已修复
- [ ] 修复引入的新问题？
- [ ] 存档/读档正常（退出 -> 重进 -> 数据保留）
- [ ] 所有核心玩法功能正常

---

## 阶段 F：上线前检查

- [ ] 合规代码就绪（隐私政策弹窗、实名认证、内容安全）
- [ ] 素材版权确认（所有图片/音频/字体有授权证明）
- [ ] 版本号正确更新
- [ ] 关闭了所有 `console.log` 调试输出（或仅在 debug 模式下）
- [ ] 构建是 release 模式（非 debug）
