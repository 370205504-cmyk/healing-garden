# 治愈花园游戏UI设计需求

## 项目概述
- **游戏名称**: 治愈花园（Healing Garden）
- **游戏类型**: 竖屏休闲解压种植合成游戏
- **目标平台**: 微信小游戏、抖音小游戏（竖屏）
- **核心玩法**: 种植植物 → 合成升级 → 装饰花园 → 社交分享
- **设计理念**: 治愈系、放松、温暖、有成就感

## 设计风格要求

### 视觉风格
- **美学方向**: 手绘治愈风格，非通用AI美学
- **色彩方案**: 柔和、温暖、治愈系色调
  - 主色调: 薄荷绿、浅天蓝、暖棕色
  - 辅助色: 柔和的粉、紫、黄
  - 强调色: 温暖的金色、橙色
- **字体选择**: 圆润、可爱的手写风格字体，避免通用字体
- **图标风格**: 手绘线描风格，略带卡通感但不幼稚
- **动效原则**: 柔和、自然、有弹性，如植物生长、微风拂过

### 设计约束
- **屏幕尺寸**: 竖屏，适配720×1280分辨率
- **操作区域**: 所有点击区域≥44×44px
- **信息层次**: 清晰的信息层级，重要信息突出
- **一致性**: 所有界面保持统一的视觉语言

## 核心界面设计需求

### 界面1：游戏主界面
#### 布局结构（从上到下）
1. **顶部信息栏** (高度12%)
   - 左侧: 玩家等级、经验进度条
   - 中间: 游戏Logo或标题（可选）
   - 右侧: 金币数量、钻石数量（高级货币）

2. **核心游戏区** (高度70%)
   - **花园网格**: 4行×6列（可扩展）的种植格子
   - 每个格子状态: 空置/种植中/可收获/枯萎
   - 网格背景: 手绘风格的草地、小径、围栏
   - 网格间装饰: 小蝴蝶、萤火虫等动态元素

3. **底部功能栏** (高度18%)
   - 5个主要功能按钮: 种子、图鉴、装饰、背包、好友
   - 按钮设计: 圆形或圆角矩形，带图标和文字
   - 交互反馈: 点击时有轻微缩放和颜色变化

#### 视觉细节
- **背景**: 渐变天空（浅蓝到淡紫），有缓慢飘动的云朵
- **前景**: 手绘风格的草地、花朵、小动物装饰
- **动态元素**: 蝴蝶飞舞、萤火虫闪烁、微风效果
- **光照**: 柔和的阳光光晕，随时间轻微变化

### 界面2：种子商店界面
#### 布局结构
1. **顶部标题**: "种子商店"
2. **种子分类标签**: 普通、稀有、史诗、传说
3. **种子列表**: 网格布局，每行3-4个种子
4. **种子卡片**: 包含种子图标、名称、价格、描述
5. **购买按钮**: 明显的购买操作区域
6. **底部关闭按钮**

#### 设计要点
- 种子图标: 精美的手绘风格，每种植物独特
- 价格显示: 清晰的货币图标和数字
- 库存状态: 已拥有/可购买/已售罄的视觉区分
- 购买反馈: 购买成功时有金币飞入动画

### 界面3：植物详情界面
#### 布局结构
1. **植物大图**: 居中显示，有轻微浮动动画
2. **植物名称和等级**: 醒目显示
3. **属性信息**: 生长时间、收益、特殊效果
4. **合成信息**: 可合成的更高级植物
5. **操作按钮**: 种植、加速、分享等
6. **背景**: 模糊的游戏主界面背景

#### 设计要点
- 植物展示: 高质量插图，展示不同生长阶段
- 信息可视化: 用进度条、图标等直观展示属性
- 情感连接: 添加植物的小故事或治愈语录

### 界面4：花园装饰界面
#### 布局结构
1. **装饰分类**: 功能性装饰、美观性装饰、主题装饰
2. **装饰网格**: 可拖拽摆放的装饰物品
3. **装饰详情**: 选中装饰物显示属性和效果
4. **预览模式**: 可预览装饰效果
5. **保存/取消按钮**

#### 设计要点
- 装饰物品: 各种手绘风格的花园装饰
- 布局自由: 支持自由拖拽和旋转
- 效果预览: 实时显示装饰对花园的影响
- 主题系统: 不同主题的装饰套装

## 交互设计需求

### 交互反馈
1. **点击反馈**: 按钮有缩放和颜色变化
2. **拖拽反馈**: 装饰物拖拽时有半透明和阴影
3. **生长反馈**: 植物生长时有进度动画
4. **合成反馈**: 合成成功时有特效动画
5. **收获反馈**: 收获时有金币飞出的动画

### 手势操作
1. **点击**: 选择、确认、收获
2. **拖拽**: 移动植物、放置装饰
3. **长按**: 查看详情、快速操作
4. **滑动**: 浏览列表、切换标签

### 动效设计
1. **界面过渡**: 柔和的淡入淡出、滑动过渡
2. **元素出现**: 有弹性的出现动画
3. **状态变化**: 平滑的状态转换动画
4. **特殊效果**: 合成、升级等特殊时刻的庆祝动画

## 技术实现考虑

### 性能优化
- 图片资源适当压缩
- 动画使用CSS transform实现硬件加速
- 避免过多复杂阴影和渐变
- 使用精灵图减少HTTP请求

### 跨平台适配
- 确保在微信、抖音环境中正常显示
- 考虑不同设备的屏幕尺寸和分辨率
- 适配不同平台的交互规范

### 可维护性
- 使用CSS变量管理颜色和尺寸
- 组件化设计，便于复用
- 清晰的注释和文档
